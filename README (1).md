# Example projects

Open these in BNBC Frame MAS with **Model → Project → Open file**. The Building page then shows every input and result.

| File | Building |
| --- | --- |
| `six-storey-dhaka-imrf.frmas` | Six storeys, Dhaka, zone 2, site class SC, SDC C, intermediate RC moment frame |
| `ten-storey-sylhet-smrf.frmas` | Ten storeys, Sylhet, zone 4, site class SC, SDC D, special RC moment frame |

Both pass every serviceability check.
